Home Assistant Blueprint

Stellt den Home-Assistant-Blueprint für die Beet-Bewässerung bereit.

GardenGlow Bewässerungs-Blueprint

Importiere den Blueprint in Home Assistant. Wähle beim Erstellen der Automation Startzeit, Switch oder Valve, optionalen Minuten-Helfer, Beet-ID und Token aus. Der Blueprint startet täglich zur ausgewählten Uhrzeit, ruft von GardenGlow die Bewässerungsminuten ab, schreibt sie optional in den numerischen Helfer und schaltet danach die Bewässerung für genau diese Dauer ein.

Einmalig benötigter RESTful Command in Home Assistant

Der Blueprint kann den Webservice-Aufruf nicht selbst als neue Home-Assistant-Integration anlegen. Füge deshalb diesen Copy-&-Paste-Block in die Home-Assistant-configuration.yaml ein und starte Home Assistant neu bzw. lade die YAML-Konfiguration neu. Danach kann der Blueprint rest_command.gardenglow_get_irrigation_minutes verwenden.

rest_command:
  gardenglow_get_irrigation_minutes:
    url: "{{ gardenglow_public_base_url }}/api/locations/{{ '{{' }} bed_id {{ '}}' }}/irrigation-prediction"
    method: GET
    headers:
      X-API-Key: "{{ '{{' }} api_token {{ '}}' }}"
  1. configuration.yaml in Home Assistant öffnen.
  2. Den YAML-Block oben einfügen. Falls bereits ein rest_command:-Abschnitt existiert, nur den eingerückten Eintrag gardenglow_get_irrigation_minutes: darunter ergänzen.
  3. Home Assistant neu starten oder die YAML-Konfiguration neu laden.
  4. Blueprint importieren, Automation anlegen und API-Token, Beet-ID, Startzeit sowie Switch/Valve auswählen.

Machine Learning

Bewässerungs-Prognose

Das Modell wird beim Abruf höchstens einmal pro Woche je Beet aus den vorhandenen Sensor-Zeitreihen neu trainiert. Negative Vorhersagen werden zu 0 Minuten.

Webservice: GET /api/irrigation-predictions oder GET /api/locations/<id>/irrigation-prediction mit dem konfigurierten Widget-API-Key.

Kalibrierung

Dezimaltrennzeichen: Du kannst Koordinaten mit Komma oder Punkt eingeben (z. B. 50,795600).

  1. Lade auf geoportal.nrw (oder einer anderen Quelle) ein Luftbild herunter und lade es oben hoch.
  2. Markiere im Luftbild zwei gut erkennbare Punkte, die möglichst weit auseinanderliegen (in X und Y).
  3. Miss die exakten Koordinaten der beiden Punkte im Geoportal aus und trage sie hier ein, z. B. Lat 50,795600 und Lon 6,126900.
Bildpunkte setzen: Nacheinander Punkt 1 und Punkt 2 im Bild anklicken.
